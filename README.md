# Пример проекта с репозиторием на github

Тестовый репозиторий для освоения гитхаб.

1. **Выгрузка существующего проекта на GitHub.**

  * создать репозиторий на GitHub (public, .gitignore for C++, README.md), скопировать на него ссылку <URL>.git
  * открыть Git Bash консоль в папке проекта
  ```
  Например: cd Onedrive/Desktop/decision/project
  ```
  * проинициализировать в этой папке git:
  ```
  git init
  ```
  * закрепить за папкой проекта репозиторий на GitHub:
  ```
  git remote add origin <URL>.git
  ```
  * если текущая рабочая ветка называется master, переименовать в новом стиле:
  ```
  git branch -M main
  ```

2. **Подготовка изменений.**

  * сохранить все изменившиеся:
  ```
  git add .
  ```
  * сохранить конкретные:
  ```
  git add file.cpp
  git add file.h
  fit add folder
  ...
  ```
  * убрать из сохранения файл / папку:
  ```
  git reset extra_file.cpp
  ``` 
  * проверить состояние файлов и их готовность к комиту:
  ```
  git status
  ```
  * сохранить текущее состояние выбранных файлов:
  ```
  git commit -m "что было сделано?"
  ```
  * посмотреть историю коммитов:
  ```
  git log
  ```

3. **работа с уже существующими репозиториями**

  * отправить имеющиеся сохранения на GitHub в ветку main:
  ```
  git push origin main
  ```

  * подтянуть с GitHub файлы .gitignore и README.md:
  ```
  git pull origin main
  ```
   * отправить имеющиеся сохранения на GitHub в ветку main:
  ```
  git push origin main
  ```
   * скачивание готово репозитория
  ```
  git clone <URL>.git
  cd <имя репозитория>
  ```

4. **Ветки и переходы**

   создать ветку:
  ```
  git branch dev
  ```

  * перейти в ветку:
  ```
  git checkout dev
  ```
  
  * создать ветку и сразу перейти в нее:
  ```
  git checkout -b dev
  ```
  * перейти в существующий коммит:
  ```
  git checkout <хеш айди коммита>
  ```

5. **Работа с файлами**

  * добавить файл сразу с текстом:
  ```
  echo "you text" > file.txt
  echo ".env" > .gitignore
  ...
  ```
  * в уже существующий файл:
  ```
  echo "pycache/" >> .gitignore
  ```
  * посмотреть файлы в папке:
```
#для обычных файлов
dir

#для всех,даже скрытых
ls
```
- удаление файлов
```
#удаление файла
rm filename.txt

# Удалить пустую папку (или можно использовать rmdir)
rm -d my_folder

# Удалить папку со всеми файлами и подпапками внутри
rm -r my_folder

# Удалить папку принудительно (игнорируя ошибки и защищенные файлы)
rm -rf my_folder
```
